# 🚀 Быстрый старт Graphite1212

## Шаг 1: Установка зависимостей

```bash
cd graphite1212
npm install
```

## Шаг 2: Запуск dev сервера

```bash
npm run dev
```

## Шаг 3: Откройте браузер

Перейдите по адресу: http://localhost:3000

---

## 📋 Основные страницы:

- **/** - Главная страница со слайдером и популярными играми
- **/library** - Библиотека игр с фильтрами и поиском
- **/profile** - Профиль пользователя с достижениями

---

## 🎨 Возможности кастомизации:

### Изменить цвета:
Отредактируйте `tailwind.config.js`:
```javascript
colors: {
  primary: '#00ff88',  // Ваш цвет
  secondary: '#ff00ff', // Ваш цвет
  // ...
}
```

### Добавить свои игры:
Отредактируйте `app/page.js` и `components/GameLibrary/index.jsx`:
```javascript
const mockGames = [
  {
    title: 'Ваша игра',
    description: 'Описание',
    // ...
  }
]
```

### Изменить шрифт:
Отредактируйте `app/layout.js`:
```javascript
<link href="https://fonts.googleapis.com/css2?family=YourFont" />
```
