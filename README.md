# 🎮 Graphite1212 - Геймерская Платформа

Современная геймерская платформа с неоновым дизайном, построенная на Next.js и React.

## ✨ Особенности

- 🎨 **Dark Mode дизайн** с неоновыми акцентами
- 🎬 **Динамический Hero слайдер** с автоматической сменой слайдов
- 🎯 **Интерактивные карточки игр** с hover-эффектами и анимациями
- 📚 **Библиотека игр** с фильтрами по жанрам, платформам и сортировкой
- 👤 **Профиль пользователя** с достижениями, статистикой и прогрессом
- 👥 **Социальные функции** - активность друзей, статусы онлайн
- ⚡ **Плавные анимации** с помощью Framer Motion
- 📱 **Адаптивный дизайн** для всех устройств

## 🚀 Технологии

- **Next.js 14** - React фреймворк с App Router
- **React 18** - UI библиотека
- **Tailwind CSS** - Utility-first CSS
- **Framer Motion** - Библиотека анимаций
- **React Icons** - Иконки

## 📦 Установка

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev сервер:
```bash
npm run dev
```

3. Откройте браузер:
```
http://localhost:3000
```

## 🎨 Компоненты

### Header
- Адаптивное навигационное меню
- Поиск
- Уведомления
- Профиль пользователя

### Hero
- Автоматический слайдер с 3 слайдами
- Навигация стрелками
- Точечная индикация
- Parallax эффект

### GameCard
- Hover анимации
- Показ видео-превью (placeholder)
- Быстрые действия
- Прогресс-бар для игр

### GameLibrary
- Фильтры по жанрам и платформам
- Поиск игр
- Сортировка
- Адаптивная сетка

### Profile
- Статистика пользователя
- Недавние игры
- Достижения
- Прогресс уровня

### FriendsActivity
- Список друзей
- Статусы онлайн/оффлайн
- Текущая активность
- Быстрые действия
